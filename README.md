# سامانه آموزش و پرورش استان اصفهان

سامانه وب فارسی و راست‌به‌چپ برای مدیریت مدرسه، ثبت نمرات، اطلاعیه‌ها و اعتراض دانش‌آموزان. بک‌اند با Flask و SQLAlchemy نوشته شده و برای PostgreSQL مدیریت‌شده آروان‌کلاد آماده است.

## امکانات

### مدیر مدرسه
- افزودن، ویرایش و حذف معلم و دانش‌آموز
- ساخت و ویرایش پایه، کلاس و درس‌های مستقل برای هر پایه
- تخصیص معلم به کلاس و درس
- تعیین نماینده کلاس
- ثبت و ویرایش نمرات تکوینی و پایانی
- قفل تکوینی، پایانی یا هر دو و بازگشایی هر بخش
- ارسال اطلاعیه برای همه، معلمان، دانش‌آموزان، یک کلاس یا یک فرد
- تغییر/بازنشانی نام کاربری و رمز عبور کاربران

### معلم
- مشاهده فقط کلاس/درس‌هایی که مدیر به او تخصیص داده است
- ثبت موقت نمرات
- ثبت نهایی تکوینی یا پایانی؛ ثبت نهایی ابتدا نمرات همان بخش را ذخیره و سپس آن بخش را قفل می‌کند
- مشاهده اطلاعیه‌های مربوط به خود
- مشاهده اعتراض‌های مربوط به کلاس/درس‌های خودش
- تأیید اعتراض همراه با ثبت نمره جدید، یا رد اعتراض همراه با علت

### دانش‌آموز
- مشاهده کارنامه خود
- مشاهده اطلاعیه‌های عمومی، دانش‌آموزی، کلاسی و فردی
- مشاهده معلم هر درس در کلاس خود
- ثبت اعتراض با انتخاب درس، بخش تکوینی/پایانی و علت

## منطق نمره

`نمره درس = (تکوینی + پایانی) / 2`

نمره درس در دیتابیس به‌صورت جداگانه ذخیره نمی‌شود و از دو مقدار اصلی محاسبه می‌شود تا همیشه سازگار بماند.

قفل نمرات در سطح `کلاس + درس + بخش (تکوینی/پایانی)` است. بعد از ثبت نهایی توسط معلم، فقط مدیر می‌تواند آن بخش را بازگشایی کند. اگر اعتراض تأیید شود ولی بخش مربوطه قفل باشد، ابتدا مدیر باید آن را باز کند و سپس معلم اعتراض را تأیید و نمره جدید را ثبت کند.

## راه‌اندازی PostgreSQL روی آروان‌کلاد

1. در پنل آروان‌کلاد یک Managed PostgreSQL بسازید.
2. اطلاعات اتصال شامل Host، Port، Database، Username و Password را از پنل بردارید.
3. در Firewall دیتابیس فقط IP دستگاه/سروری را که برنامه روی آن اجرا می‌شود مجاز کنید.
4. فایل `.env.example` را با نام `.env` کپی کنید.
5. مقدار `DATABASE_URL` را با اطلاعات واقعی دیتابیس پر کنید. نمونه:

```env
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:PORT/DBNAME?sslmode=require
```

> فایل `.env` در `.gitignore` است و نباید Commit شود.

## اجرای برنامه روی سیستم

نیازمندی: Python 3.11 یا جدیدتر.

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# فایل .env را ویرایش کنید
python app.py
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# فایل .env را ویرایش کنید
python app.py
```

سپس آدرس `http://127.0.0.1:5000` را در مرورگر باز کنید.

## ساخت اولین مدیر

در `.env` این دو مقدار را قرار دهید:

```env
ADMIN_NATIONAL_ID=1234567890
ADMIN_FULL_NAME=مدیر سامانه
```

اگر هنوز هیچ مدیر در دیتابیس نباشد، هنگام اولین اجرای `python app.py` حساب مدیر ساخته می‌شود. نام کاربری و رمز اولیه همان `ADMIN_NATIONAL_ID` است. پس از ورود می‌توانید اطلاعات ورود کاربران را از پنل مدیر تغییر دهید.

## نکته امنیتی ورود کاربران

برای معلم و دانش‌آموز هنگام ساخت حساب فقط کد ملی گرفته می‌شود. سیستم به‌طور خودکار نام کاربری و رمز اولیه را همان کد ملی قرار می‌دهد، ولی رمز در دیتابیس به‌صورت Hash ذخیره می‌شود و متن خام آن ذخیره نمی‌شود. قابلیت فراموشی رمز وجود ندارد و تغییر یا بازنشانی فقط توسط مدیر انجام می‌شود.
